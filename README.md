# 猎名场 · NAMETAG ARENA

手机浏览器多人撕名牌实况对战：房间/二维码加入、角色（管理员/玩家/摄影/特殊人物）、
隐藏定位与轨迹记录、开局准备阶段/全员准备、低于 15 分钟全员显形、随机事件、8 种技能卡、
技能卡二维码、聊天、管理员自定义任务（可指定个人/可选见证码）、特殊人物技能、管理员控制台、
首页游戏说明、赛后轨迹动画回放与 HTML/WebM/JSON/PNG 导出。

## 运行

```bash
npm install
npm start            # http://127.0.0.1:4173
```

公网（手机定位需要 HTTPS）：

```bash
bash start.sh        # Node 服务 + ngrok 固定 dev 域名
```

## 技术栈

- Node.js 20+ / Express 5 / Socket.IO 4
- 原生 JS 单页应用 + Leaflet（高德瓦片，WGS84→GCJ02 纠偏）
- 内存房间状态；无数据库
- 回放：Canvas 动画；HTML 单文件导出 / MediaRecorder WebM
- 二维码：qrcode 服务端生成；jsQR 网页内扫码

## 主要配置

- 端口：环境变量 `PORT`，默认 4173
- 房间：6 位数字，最多 40 人
- 默认时长 45 分钟；低时间阈值 15 分钟
- 准备阶段默认 10 分钟，可设 0–30 分钟；0 表示直接开局
- 全员准备后才能开始；管理员可强制开始；准备阶段位置全员可见、身份隐藏，不可撕/做任务
- 淘汰播报：所有设备全屏显示“名字 OUT”，管理员设备朗读；管理员投屏即现场大屏
- 首页「游戏说明」：玩法流程、身份、8 张技能卡、特殊技能、定位/见证码/二维码
- 自定义任务可指定某位玩家或全体，可选 4 位见证码；内置常州欢乐谷地点任务预设（过山车/高空/鬼屋 NPC/水上/地标/比心）
- 特殊人物：默认 1 人，可设 0–6 人；身份正式开局后公开，每人随机 1 个技能，每局可多次使用，每次使用后冷却 3 分钟
- 技能卡二维码：管理员开局前按房间生成，或落地页生成全房间通用码；支持一次批量生成 1–30 张、可选显示/隐藏技能名称，一键导出 3 列长图；一次性核销，失效后不可复用
- 撕名牌距离：默认 30 米（可设 0 关闭校验）
- 公网使用 ngrok 固定 dev 域名（.ngrok.env 保存 authtoken/domain，已排除在源码 zip 外）
- 重启服务网址不变；第一次访问需在 ngrok 提示页点 Visit Site
- 免费 ngrok 有月流量限制；彻底稳定可部署到云服务器

## 安全与数据

- 玩家身份用随机 token 校验；房间码 + token 进入。
- 位置只按规则下发给有权查看的客户端。
- 所有房间数据在内存中，进程重启即丢失；赛后请导出回放。
- 公开链接请只发给同学；房主可锁定房间、踢人、解散。
